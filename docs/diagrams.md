# Architecture diagrams

[Back to README](../README.md)

These diagrams follow the [awslabs AWS architecture diagram skill](https://github.com/awslabs/agent-plugins/tree/main/plugins/deploy-on-aws/skills/aws-architecture-diagram): official AWS4 icons, category colors, numbered flows, and editable draw.io XML. They describe the application code, CloudFormation templates, and deployment configuration checked on **2026-09-12**.

The PNGs include embedded diagram XML and can also be opened in draw.io. The uncompressed `.drawio` files are retained for readable diffs and direct editing. Browser preview links below contain the diagram in the URL fragment and do not depend on repository access.

## Regenerate and export

The generator uses only Python's standard library. Run from the repository root:

```bash
python3 tools/generate_architecture_diagrams.py
```

This overwrites all three `.drawio` files in `docs/`. Make durable layout changes in the generator; direct edits in draw.io will otherwise be replaced by the next generation.

Export each preview using [draw.io desktop](https://github.com/jgraph/drawio-desktop):

```bash
for name in application-architecture cicd-pipeline-architecture github-pipeline-architecture; do
  drawio -x -f png -e -b 20 -s 1.5 \
    -o "generated-diagrams/$name.png" "docs/$name.drawio"
done
```

On macOS, the CLI is also available at `/Applications/draw.io.app/Contents/MacOS/draw.io`. `-e` embeds the editable XML in each PNG; `-s 1.5` keeps text legible when opening the full-size image.

## Validation and preview links

When the `deploy-on-aws` plugin is installed, its diagram hook supplies validation and layout fixers. For a standalone checkout, run its tools explicitly with `<plugin-root>` pointing to `plugins/deploy-on-aws` in the agent-plugins repository:

```bash
python3 <plugin-root>/scripts/lib/validate_drawio.py docs/application-architecture.drawio
python3 <plugin-root>/scripts/lib/fix_step_badges.py docs/application-architecture.drawio
python3 <plugin-root>/scripts/lib/drawio_url.py docs/application-architecture.drawio --open
```

Repeat for the other two sources, then refresh the browser links above from `drawio_url.py` output after any diagram change. These helpers require `defusedxml`. The generator and desktop exporter do not.

All three diagrams passed the skill's XML validator and badge-overlap check and were visually inspected after export. The downloaded helper revision had Python 3.12 compatibility issues in its post-processing imports/type annotations; validation used scratch copies with postponed annotations and explicit module registration. Those compatibility edits do not change diagram validation rules and are not runtime application dependencies.

Check both the XML and the image after updates: valid XML alone does not establish accurate flows, readable labels, or correct AWS region boundaries. Keep runtime and release flows separate, label the retained GitHub path clearly, and update the README plus historical design-document references when filenames change.
